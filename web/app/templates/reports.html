What goes into a report

  • Cover & chain of custody — file name, size, MD5/SHA-256, acquisition time, detected OS and profile.
  • Executive summary — risk score, severity breakdown, and the headline findings in plain language.
  • Triage findings — every indicator with its rule ID, the row that triggered it, and the recommended next step.
  • Plugin output — one table per run, with the exact command line that produced it so the work is reproducible.
  • Execution log (ZIP bundle only) — raw stdout/stderr per run.

PDF export uses WeasyPrint inside the web container. If PDF fails, generate HTML and print to PDF from the browser — the report stylesheet has a print mode.
